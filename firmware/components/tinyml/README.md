# tinyml (Derya)

The learned model on the node: int8 TensorFlow Lite Micro model and the code
that runs it. Same input and output as the baseline: last 24 h (288 samples
of VWC and VPD) in, 36-step (3 h) VWC forecast out.

## Selected model: linear forecaster

A small MLP was tried and did not beat a linear model on unseen greenhouses
(larger MLPs overfit the training greenhouse), so the model is linear: one
dense layer, 576 inputs -> 36 outputs, 20,772 parameters.

- Inputs: 288 soil values minus the current value (% of field capacity) and 288 VPD values (kPa).
- Output: change of soil moisture for the next 36 steps, added to the current value.
- Training, evaluation and weights: `deryaauysl/sagriot`, `src/linear_model.py`.
- Float version in the cloud: `cloud/derya_model.py` (`--model tinyml=derya_model:predict`).

| Train -> test (AGC) | Events caught | Warnings real | Physics model caught |
|---|---|---|---|
| MuGrow -> AgriFusion | 54.6 % | 86.8 % | 14.8 % |
| AgriFusion -> MuGrow | 45.2 % | 88.7 % | 24.0 % |

## On the node (this component)

Plain C, no TensorFlow Lite Micro: the model is one dense layer, so a
loop over the weights is all it needs (no interpreter, no tensor arena).

- `tinyml_forecast(&buf, site_bias, out)` reads the baseline's 24 h ring
  buffer (no second copy in RAM) and writes the 36-step VWC forecast.
  `site_bias` is the cloud's learned bias for this site (36 values) or NULL.
- `baseline_decide_forecast(&buf, out)` makes the decision with the
  baseline's rule (soil < 70 % FC now / within 3 h).
- Weights: `tinyml_weights.c`, generated by `tools/export_tinyml.py`
  from `cloud/derya_model.npz`. Rerun it whenever the model is retrained
  (`cloud/tests/test_tinyml_port.py` fails until you do).

Quantization (measured on the internship record, PC, 5,733 windows):

| Weights | Flash | Forecast error vs float (mean / max) | Same decision |
|---|---|---|---|
| all int8 | 21.0 KB | 0.193 / 1.19 VWC | 99.41 % |
| soil int16 + VPD int8 (used) | 31.5 KB | 0.018 / 0.029 VWC | 99.91 % |

Soil inputs reach +-50 % FC, so int8 rounding on those weights added up
to an error larger than the model's own (0.12 VWC after bias correction);
VPD inputs are ~1 kPa and int8 is enough for them.
